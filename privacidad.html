Política de privacidad / Privacy Policy

Última actualización / Last updated: 18 de noviembre de 2026 / November 18, 2026

Español

rclone-ghostnas es una herramienta de uso personal basada en rclone. Su único usuario es su propietario.

  • Datos a los que accede: solo los archivos de la cuenta de Google Drive del propietario, con el fin de subir y eliminar copias de respaldo de su servidor doméstico.
  • Uso de los datos: los archivos se usan exclusivamente para almacenar y rotar respaldos. No se analizan ni se procesan con ningún otro fin.
  • Compartición: no se comparte, vende ni transfiere ningún dato a terceros.
  • Almacenamiento: las credenciales de acceso se guardan solo en el servidor del propietario. No existe ningún servidor externo de la aplicación.
  • Otros usuarios: la aplicación no recopila datos de ninguna otra persona.
  • Revocación: el acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions.

El uso de la información recibida de las APIs de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

English

rclone-ghostnas is a personal-use tool based on rclone. Its only user is its owner.

  • Data accessed: only files in the owner's own Google Drive account, in order to upload and delete backup copies from a home server.
  • Use of data: files are used solely to store and rotate backups. They are not analyzed or processed for any other purpose.
  • Sharing: no data is shared, sold, or transferred to any third party.
  • Storage: access credentials are stored only on the owner's server. There is no external application server.
  • Other users: the application does not collect data from any other person.
  • Revocation: access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
